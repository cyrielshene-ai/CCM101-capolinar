# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity focuses on learning the basics of working in a cloud-based Linux environment using KillerCoda. It also introduces proper documentation and the use of GitHub as a Cloud Computing portfolio.

## Objectives

- Access and use a cloud-based Linux environment.
- Navigate and manage files and directories using Linux commands.
- Gather basic system information.
- Create and organize Markdown files.
- Maintain a professional GitHub repository.

## Activities Performed

- Accessed the Ubuntu 24.04 environment through KillerCoda.
- Created and used the `capolinar` Linux user.
- Checked the Linux distribution, kernel version, CPU information, memory, and disk space.
- Created the `Notes`, `Reports`, and `Screenshots` directories.
- Created Markdown documentation files.
- Created a public GitHub repository for the Cloud Computing portfolio.

## Linux Commands Used

```bash
uname -r
lscpu
free -h
df -h
mkdir Notes Reports Screenshots
cd Notes
nano about-me.md
```

## Skills Learned
Through this activity, I learned how to work with a cloud-based Linux environment, use basic Linux commands, organize files and directories, create Markdown documentation, and manage a GitHub repository. These skills will help me become more comfortable with cloud infrastructure and technical documantation.
