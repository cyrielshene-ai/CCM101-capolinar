# Reflection

This laboratory activity gave me a better understanding of how cloud-based Linux environments work. Using KillerCoda allowed me to practice basic Linux commands without installing a separate operating system on my computer.

I learned how to create and manage a Linux user account, navigate directories, and gather important system information such as the Linux distribution, kernel version, CPU, memory, and available disk space. I also learned how to create and organize files using Linux commands.

One of the most useful parts of the activity was learning how to use GitHub as a portfolio. I was able to create a public repository and organize my laboratory files using Markdown. This helped me understand the importance of proper documentation and version control in Cloud Computing.

Overall, this activity improved my confidence in using Linux and GitHub. I believe the skills I learned here will be useful in future cloud computing activities and other IT projects.
